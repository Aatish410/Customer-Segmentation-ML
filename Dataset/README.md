# Dataset

Download the official **UCI Online Retail** dataset into this folder by running:

```bash
python Source_Code/download_data.py
```

The script saves `Online Retail.xlsx` (or a CSV fallback) here. The dataset is not bundled in this project archive because it is a separate 22.6 MB source file. Official source: https://archive.ics.uci.edu/dataset/352/online+retail

Dataset citation: Chen, D. (2015). *Online Retail* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5BW33. License: CC BY 4.0.
